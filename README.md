# Tempio Malatestiano – Enriching ArCo with SPARQL and LLMs

KE4H (Knowledge Engineering for the Humanities) project, University of Bologna.  
Author: **Sofia Bianchini**

**Website:** <https://sofiabianchiniweb.github.io/KE4H_Project/>

The project explores how the [Tempio Malatestiano](https://en.wikipedia.org/wiki/Tempio_Malatestiano) of Rimini is described in [ArCo](https://w3id.org/arco), the Italian Cultural Heritage Knowledge Graph. SPARQL queries were used to identify missing information (authorship, commission and a historical description), ChatGPT and Gemini were used with three prompting techniques to research it, and the verified facts were translated into RDF triples based on ArCo's ontologies.
